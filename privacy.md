# Privacy policy

These tools are for personal use by their owner only, with his own accounts. There are no other users.

The tools read and organise information in the owner's own accounts so he can manage them. Data the tools access stays with the owner, is kept only as long as needed and can be deleted at any time. It is not sold, not shared with anyone and not used for advertising.

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
